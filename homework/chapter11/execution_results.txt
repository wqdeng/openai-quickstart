```java
public class MatrixMultiplication {
    /**
     * 计算两个矩阵的乘积
     *
     * @param A 第一矩阵（行维数 x 列维数）
     * @param B 第二矩阵（列维数 x 行维数）
     * @return 相乘结果的矩阵
     */
    public static double[][] multiplyMatrices(double[][] A, double[][] B) {
        // 检查两矩阵是否能够相乘
        if (A[0].length != B.length) {
            throw new IllegalArgumentException("列维数必须相等才能进行矩阵乘法");
        }

        int rows = A.length;
        int cols = B[0].length;
        int inner = A[0].length;

        // 初始化结果矩阵
        double[][] result = new double[rows][cols];

        // 计算矩阵乘积
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                for (int k = 0; k < inner; k++) {
                    result[i][j] += A[i][k] * B[k][j];
                }
            }
        }

        return result;
    }

    public static void main(String[] args) {
        // 示例使用
        double[][] matrixA = {{1, 2}, {3, 4}};
        double[][] matrixB = {{5, 6}, {7, 8}};

        double[][] result = multiplyMatrices(matrixA, matrixB);

        // 输出结果
        for (double[] row : result) {
            for (double element : row) {
                System.out.print(element + " ");
            }
            System.out.println();
        }
    }
}
```
**功能描述**
-----------------

*   函数 `multiplyMatrices` 计算给定两个矩阵 A 和 B 的乘积。
*   参数：
    *   `A`: 第一矩阵（行维数 x 列维数）
    *   `B`: 第二矩阵（列维数 x 行维数）
*   返回：相乘结果的矩阵
*   支持 2Ddouble[][]数据类型

```java
public class MatrixMultiplication {
    /**
     * 计算两个矩阵的乘积
     *
     * @param A 第一矩阵（行维数 x 列维数）
     * @param B 第二矩阵（列维数 x 行维数）
     * @return 相乘结果的矩阵
     */
    public static double[][] multiplyMatrices(double[][] A, double[][] B) {
        // 检查两矩阵是否能够相乘
        if (A[0].length != B.length) {
            throw new IllegalArgumentException("列维数必须相等才能进行矩阵乘法");
        }

        int rows = A.length;
        int cols = B[0].length;
        int inner = A[0].length;

        // 初始化结果矩阵
        double[][] result = new double[rows][cols];

        // 计算矩阵乘积
        ExecutorService executor = Executors.newFixedThreadPool(rows);
        List<Future<Double>> futures = new ArrayList<>();

        for (int i = 0; i < rows; i++) {
            final int indexI = i;
            Future<Double> future = executor.submit(() -> {
                double sum = 0;
                for (int j = 0; j < cols; j++) {
                    sum += A[indexI][j] * B[j][indexI];
                }
                return sum;
            });
            futures.add(future);
        }

        // 等待所有线程完成
        for (Future<Double> future : futures) {
            try {
                result[futures.indexOf(future)][0] = future.get();
            } catch (InterruptedException | ExecutionException e) {
                Thread.currentThread().interrupt();
                return null;
            }
        }

        executor.shutdown();

        return result;
    }

    public static void main(String[] args) {
        // 示例使用
        double[][] matrixA = {{1, 2}, {3, 4}};
        double[][] matrixB = {{5, 6}, {7, 8}};

        double[][] result = multiplyMatrices(matrixA, matrixB);

        // 输出结果
        for (double[] row : result) {
            for (double element : row) {
                System.out.print(element + " ");
            }
            System.out.println();
        }
    }
}
```
该修改使用 Java 的多线程 API，ExecutorService 和 Future 类，让每个矩阵乘法操作在不同的线程中执行。通过这种方式，您可以提高计算效率，并利用多核处理器的优势。
